# Natura WhatsApp Groups

Installable group directory for Natura residents. Open https://brunopons2.github.io/natura-whatsapp-groups/ in Safari or Chrome and choose Add to Home Screen.

Group information is maintained in data/groups.js. Administrator contacts in data/administrator-contacts.json are a snapshot and must be updated when the Residents Directory changes.

The app caches its directory for offline use. WhatsApp invitations and communication actions require the relevant apps and connectivity.
